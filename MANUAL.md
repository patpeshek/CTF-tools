# MANUAL — то, что скрипты не делают

Скрипты закрывают один шаг: распаковать, декодировать, вытащить биты. Всё остальное —
ты: понять условие, выбрать ход, собрать цепочку, заметить аномалию. Этот файл — про
ручную работу и про то, как быстро понять, что тебе нужно прямо сейчас.

## 0. Перед любым действием

0. Если совсем не понятно, что перед тобой — `python toolbox.py auto <файл|строка>`.
1. **Что мне дали?** файл / ссылка / сервис с портом / просто текст / ничего.
2. **Что просят вернуть?** флаг, число, название, отчёт. Формат ответа — в условии.
3. **Какая категория заявлена?** На платформе она почти всегда указана — это половина подсказки.
4. **Какой самый дешёвый первый шаг?** `file`, `strings`, открыть в браузере, `exiftool`,
   `python triage.py`.
5. **Что я уже проверил и что этим исключил?** Если ответа нет — ты не «застрял», ты
   просто ещё не сформулировал гипотезу.

Если после двух разных гипотез результата нет — не третья косметическая попытка,
а смена категории подхода: файл → сеть → веб → крипта → память.

## 1. Как читать условие

Легенда часто кодирует метод, а не украшение:

| Слова в условии | Что это значит |
|---|---|
| «зеркала», «отражения» | две картинки, diff, LSB, реверс строки |
| «три отражения», «три слоя» | три вложенных файла/кодировки |
| «эхо», «повтор» | повторяющийся ключ, XOR, RLE |
| «следы», «дневник», «удалено» | образ диска, photorec, логи, mtime |
| «почти уцелел пароль, два символа *» | брут ровно двух символов, не всего пароля |
| «аномалия в трафике» | один пакет отличается размером/портом/payload |
| «классика», «старина» | Цезарь/Виженер/морзе/Плейфер |
| «я изобрёл шифр» | дан код — писать обратную функцию, а не гадать |
| «(NO)», «?», «лол» | сарказм = подсказка на конкретный баг |
| «учётка высшего уровня» | IDOR/JWT/брут/утечка, а не «взломай пароль» |

Формат флага — это ограничение: `CTF{[A-Z]{6}}`, `ctf{some_word}`, `flag{...}`.
Проверяй регистр и обёртку до сдачи.

**Отдай условие автопилоту.** `solve` читает текст задачи и меняет план:

```powershell
python toolbox.py solve task.bin --desc "XOR, потом base64. Формат флага: ABC{...}"
python toolbox.py solve task.bin --desc-file statement.txt     # UTF-8
python toolbox.py solve --desc "nc host 31337, ответь на 100 раундов"   # цель из условия
```

Что берётся из текста (RU/EN): категория (явная `Категория: X` весит больше слов
легенды), подсказки (`xor`, `rsa`, `lsb`, `base64`, `морзе`, `steghide`, «пароль от
архива», Виженер, Цезарь, слои/цепочка, …) — их инструменты идут первыми; формат
флага (`flag format: ABC{...}`, `формат флага ...`, шаблон `ABC{<...>}`) — префикс
добавляется в начало списка префиксов (видят и все шаги, и `xorknown --known`);
пароли/ключи (`password: "x"`, `ключ «x»`, `key=… iv=…`) — в шаги, которые их
принимают (`xorknown --key`, `ecb`/`aes --key`, `classical vigenere --key`, словарь
для хешей); URL и `host:port`/`nc host port` — цель, если её не дали. Разбор
печатается в шапке плана (`[+] условие: …`), функция — `solve.parse_statement()`.

## 2. OSINT вручную

**Обратный поиск картинки.** Яндекс.Картинки → Google Lens → Bing → TinEye.
Если не находится: обрезать до объекта, убрать интерфейс, повернуть/отразить,
искать по деталям (узор, вывеска, отражение в стекле).

**Геолокация.** Язык вывесок, формат номеров, сторона движения, архитектура,
растительность, столбы и бордюры, тени (SunCalc по времени съёмки), Яндекс.Панорамы
и Street View. Проверяй по двум независимым признакам.

**Люди и компании.** Поиск по username, архивные страницы (Wayback Machine),
WHOIS, вакансии, соцсети. Не трогай частных лиц — только публичные источники.

**Время.** EXIF → часовой пояс → расписание/новость/событие. `misc/timeconv.py`.

## 3. Web вручную

Порядок:

1. **Карта приложения.** Все страницы, формы, роли, запросы, cookies, JS.
2. **Каждый вход** проверь на: `'`, `"`, `<script>`, `{{7*7}}`, `${7*7}`, `../../`,
   `%00`, огромное число, отрицательное число, пустую строку.
3. **Смотри на разницу ответов**: код, длина, время, редирект, текст ошибки.
4. **Читай исходники и JS**, если дали. Комментарии, `sourceMappingURL`, скрытые поля.
5. **Логика**: отрицательное количество, округление, повторное применение купона,
   гонка (два запроса одновременно), смена роли.
6. **Авторизация**: JWT (декодируй, меняй `sub`/`role`/`user_id`, `alg:none`,
   слабый секрет), куки, заголовки.
7. **Файлы**: расширение, content-type, magic bytes, zip-symlink, куда лёг файл.
8. **Когда повторять вручную больше 20 раз** — пиши цикл на Python/Intruder.

Ручное важно: именно руками находятся «странности», которые скрипт не заметит.

## 4. Crypto: определить шифр по виду

| Что видишь | Что это, скорее всего |
|---|---|
| только буквы, пробелы сохранены | Цезарь / аффинный / замена |
| буквы без пробелов, 5×5 таблица в условии | Плейфер |
| числа 0–25 | аффинный |
| буквы + ключ в условии | Виженер |
| `A/C/G/U` или `U`-триплеты | генетический код |
| точки/тире | морзе |
| цифры группами (`222 33`) | multitap |
| `=` на конце, алфавит base64 | base64 |
| только `0-9a-f`, чётная длина | hex |
| «два сообщения XOR», ключ по маске | XOR + known plaintext |
| большое число + модуль | RSA/модульная арифметика |
| блоки по 16 байт, бинарник | AES |
| «пароль по времени» | PRNG seed |

Если дан код — **не подбирай**, а напиши обратную функцию и проверь на известном
префиксе. Частотный анализ: индекс совпадения, частые триграммы, dcode.fr.

## 5. Reverse вручную

1. `file`, `strings -a`, `rabin2 -I`/Detect It Easy.
2. Запусти и посмотри поведение; для Windows — Procmon, для Linux — strace.
3. Ghidra: `main`, сравнения, строки рядом с проверкой.
4. Ищи константы: ключ, IV, S-box, magic.
5. Python: `pycdc`/`uncompyle6`; если pyarmor — дамп памяти и поиск по загрузчику.
6. Если проверка в одном месте — можно пропатчить/перевернуть jump (но флаг обычно
   получается расшифровкой, а не патчем).

## 6. Network вручную

Wireshark: Statistics → Protocol Hierarchy → Conversations → фильтр → Follow Stream →
File → Export Objects.

Что искать:

- необычный размер/порт/протокол;
- логины и пароли в cleartext;
- DNS-туннель: длинные поддомены, частые запросы;
- ICMP/DNS payload с hex/base64;
- HTTP-путь с параметром (`activation_code=...`);
- последовательность «скан → эксплуатация → закрепление → удаление следов».

Отвечай ровно на вопрос задачи: «кто», «что», «куда», «когда». Лишнее не спрашивают.

## 7. Forensic вручную

- **Таймлайн**: mtime/atime/ctime, EXIF, логи.
- **Удалённое**: photorec/testdisk, slack space, `.bash_history`.
- **Архивы**: комментарии, имена, даты, extra-поля.
- **Скрытое**: стего-слой, base64 в логах, пароль рядом.
- **Вывод**: что произошло, кто, когда, какими средствами.

## 8. PWN вручную

`checksec` → запуск → падение → паттерн → оффсет → адрес win → payload → отладка.
Если win-функции нет: ret2libc/ROP; в простых задачах такого обычно не требуется.
Если Python: `input()`/`eval`, pickle, yaml. Если bash: `read -p`, `eval`.

## 9. PPC/Admin вручную

Это задачи на автоматизацию, а не на знания:

- сокет-цикл: `recv` → разобрать → `send` → повтор;
- викторина: банк вопросов, запоминать правильные ответы между переподключениями;
- игра: минимакс/эвристика, либо перебор;
- матрица: ДП, жадность, проверка делимости;
- OCR: `pytesseract` + бинаризация.

Если задача требует «100 раундов по 2 секунды» — это всегда скрипт, руками нельзя.

## 9.5. Кастомные протоколы (не HTTP)

Порядок:

1. **Собери TCP по sequence numbers**, а не по порядку пакетов в файле.
2. **Найди границу шифрования** по первому «сломанному» пакету: до неё видно
   `[len][packet_id]`, после — мусор.
3. **Ключ часто лежит в логе клиента** (`secret=`, `key=`, `cipher=`), а не в трафике.
4. После расшифровки проверь **оба формата**: `[len][pid][data]` и
   `[len][uncompressed_len][zlib]`. Первый пакет после включения шифрования может быть
   ещё в старом формате.
5. Смотри **частые packet id**: если один id идёт тысячами — это и есть полезная нагрузка.
6. Если payload похож на координаты — собери CSV и отрисуй картинку; шрифт 5×5
   читается автоматически, иначе глазами по `--legend`.

## 9.6. Linux: что смотреть в первую очередь

1. `sudo -l` — почти всегда ответ здесь.
2. SUID/SGID и capabilities.
3. Скрипты, которые root запускает по cron/таймеру, и **можно ли их/их конфиги писать**.
4. `source`/`.` внутри root-скрипта — если файл записываемый, это root.
5. Группы: иногда достаточно быть в `root`/`docker`/`adm`.
6. Кастомная оболочка: `help` показывает белый список; `read` читает файл,
   `extract` принимает пароль, `connect` куда-то подключается. Пароль почти всегда
   считается из открытого скрипта и открытых файлов — повтори вычисление локально.

## 9.7. Повтор потока, PNG-метаданные, мобильные выгрузки

- **Two-time pad.** Если один поток использован дважды: `c1 ^ c2 = p1 ^ p2`.
  Подставляй известные слова (crib) и смотри, где второй текст остаётся печатным.
  Инструмент: `crypto/otp_reuse.py`.
- **PNG.** Смотри `tEXt`/`zTXt`/`iTXt`, нестандартные чанки и данные после `IEND`.
  Инструмент: `stego/png_chunks.py`.
- **Android.** `android_id` и `seed` обычно в XML, пароль/ключ — в логе или SQLite.
  Инструмент: `forensic/android_backup.py`, дальше расшифровка трафика этими параметрами.

## 10. Скрипт не подходит: написать свой за 10 минут

Скелет:

```python
import sys, re, socket, requests

data = sys.stdin.read()          # или open(file,'rb').read()
# 1) выделить полезное
parts = re.findall(r"...", data)
# 2) преобразовать
result = ...
# 3) вывести
print(result)
```

Три типовых случая:

- **цикл по строкам**: `for line in data.splitlines(): ...`
- **сокет**: `s=socket.create_connection((h,p)); s.recv(4096); s.sendall(ans)`
- **перебор**: `for k in range(256): if decrypt(k).startswith(known): print(k)`

Правило: сначала проверь на маленьком примере, потом запускай на всём.

## 11. Упражнения (сделай сам)

1. Сгенерируй PNG с сообщением в LSB красного канала и вытащи его `stego/lsb.py`.
2. Сделай ZIP с комментарием-hex, перевёрнутым задом наперёд, и найди флаг.
3. Зашифруй текст Цезарем с случайным сдвигом — определи сдвиг без ключа.
4. Сделай XOR с ключом из 3 символов и известным началом — восстанови ключ.
5. Собери PCAP с POST-логином и найди пароль в Wireshark.
6. Подделай JWT `user_id=1` и проверь на локальном Flask-приложении.
7. Собери DOCX с флагом в `word/media` и вытащи его.
8. Смонтируй образ ext4, удали файл, восстанови photorec.
9. Напиши C-программу с `strcpy` и win-функцией, пройди ret2win.
10. Подними juice-shop/DVWA и пройди IDOR и SQLi руками.

## 12. Порядок работы

- Просмотри все задачи, отметь понятные и дорогие.
- Сначала бери то, что решается быстро, потом сложное.
- Правило двух заходов: два разных подхода — стоп, переключись.
- Перед сдачей проверь формат ответа: регистр, обёртка, лишние пробелы.
- В конце проверь, что все отправленные ответы действительно приняты.
