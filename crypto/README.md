# crypto

- `classical.py` — Цезарь (брут с оценкой), аффинный (по known-префиксу), Виженер
  (в т.ч. `vigenere-crack` без ключа), Атбаш, морзе, multitap, Плейфер.
- `autocrack.py` — «перебрать всё»: кодировки рекурсивно, Цезарь, аффинный, XOR
  (1 байт и повторяющийся), rail fence, ROT47, Виженер; для хешей — авто-тип,
  локальный словарь и простые мутации.
- `megacrack.py` — шифротекст + материалы: собирает токены из файлов/JSON/строк,
  делает из них ключи (raw/hex/base64/md5/sha1/sha256, пары, xor) и перебирает
  XOR, RC4, AES-ECB/CBC, SHA256-поток и Виженер.
- `genetic.py` — триплеты РНК/ДНК → аминокислоты.
- `xor_known.py` — восстановление ключа по известному началу текста, длину ключа подбирает сам.
- `prng_seed.py` — кандидаты `random`-строк по seed-timestamp.
- `aes_file.py` — AES-CBC с ключом/IV из строк (XOR, повтор, обрезка).
- `aes_ecb.py` — детект повторов блоков и расшифровка AES-ECB.
- `hash_id.py` — тип хеша и режим hashcat.
- `hashcat_run.py` — готовая команда/запуск hashcat по автоопределённому режиму.
- `rsa_tool.py` — общий множитель, общий модуль, малая экспонента, факторизация
  по `p`, Ферма, batch GCD по списку модулей, `dp-leak` (утечка `d mod p-1`),
  `smallq`, `n=p^k`, PEM/DER-ключи; `rsa auto` сам вытаскивает числа из текста,
  импортирует публичный/закрытый ключ и гоняет все атаки (p−1, rho, Винер, `e=1`,
  прямой `d`).
- `otp_reuse.py` — two-time pad: `c1^c2`, crib dragging.
- `shamir.py` — доли Шамира (поле подбирается по долям, `--robust` отбрасывает
  несогласованные, `--k` для порога) и CRT-остатки; секрет печатается числом,
  hex, ASCII и сразу ищется флаг.
- `stream_sha256.py` — `SHA256(key||nonce||counter) XOR`, с перебором кодировок.

Если алгоритм самописный — сначала прочитай код, потом пиши **обратную** функцию
и проверяй на известном префиксе. Онлайн-помощники: dcode.fr, CyberChef.
