# pwn

- `checksec.py` — защиты ELF/PE без pwntools: PIE/NX/Canary/RELRO/Fortify, ASLR/CFG.
- `ret2win.py` — de Bruijn-паттерн, поиск оффсета, сборка payload, отправка.
- `fmtstr.py` — `%N$p` для поиска оффсета, leak и write-payload'ы; `scan` гоняет
  `%1..%N$p` по живому сервису, подсвечивает ASCII и (с `--deref`) пробует `%N$s`.
- `oracle.py` — универсальный TCP-цикл для сервисов «N раундов вопросов»:
  regex вопроса, формула ответа, шаблон отправки. Скрипт под задание не нужен —
  меняется одна формула. `--peek` показывает, что вообще присылает сервис,
  `--local "команда"` гоняет локальный процесс вместо сети.
- `pwn_notes.md` — типовые уязвимости и порядок действий.

Проверь `checksec`, найди win-функцию через `objdump`/Ghidra, оффсет — паттерном.
