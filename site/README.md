# Сайт — рабочая версия

Страница кидает задачу на сервер. Сервер запускает прогон инструментов проекта и
параллельно — доработку (движок с доступом к файлам и терминалу). Что первое нашло
флаг — то и ответ. В браузере живой лог: реальные шаги, их время, вывод команд.

## Запуск

```bash
python site/app.py               # http://127.0.0.1:8770
```

Только стандартная библиотека. Инструменты проекта требуют
`pip install -r requirements.txt` и, для части шагов, внешние утилиты
(Ghidra/hashcat/tesseract) — что установлено, то и работает.

Переменные окружения: `PORT` (8770), `BIND` (127.0.0.1).

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/task` | принимает задачу (JSON), создаёт рабочую папку |
| GET | `/api/events/<id>` | SSE-поток событий; запускает работу |
| POST | `/api/terminal` | `{id, cmd}` — команда в папке задачи |
| GET | `/api/files/<id>` | список файлов задачи |
| GET | `/api/file/<id>?path=` | содержимое файла (до 200 КБ) |
| POST | `/api/stop/<id>` | остановить прогон |
| GET | `/health` | `{ok, sandbox, model}` |

### Формат задачи

```json
{
  "task": "текст условия",
  "files": [{"name": "chall.bin", "b64": "..."}],
  "inputs": [{"role": "ciphertext", "value": "..."}],
  "prefix": "ctf",
  "budget": 90,
  "deep": false
}
```

* `files` — любые файлы, включая вложенные пути (`dir/sub/file`);
* `inputs` — данные из условия: `role` из списка
  (`ciphertext`, `plaintext`, `key`, `keylen`, `nonce`, `iv`, `salt`, `hash`,
  `modulus`, `exponent`, `signature`, `password`, `hint`, `raw`);
* `budget` — секунды на прогон инструментов (10…900);
* `deep` — включить дорогие шаги.

## Как идёт работа

- **Инструменты** — `solve.py --events -`: план, шаги, зацепки, флаг.
- **Доработка** — движок с инструментами: список/чтение/запись файлов,
  запуск кода и команд, до 16 шагов. Стартует одновременно с прогоном.

События идут с пометкой `stage` (`kit` / `second`). Время в логе — фактическое.

## Настройка доработки

Нужен OpenAI-совместимый endpoint. Параметры берутся из окружения
(`SOLVER_API_URL`, `SOLVER_API_KEY`, `SOLVER_MODEL`) или из
`site/engine/.env` (в git не попадает):

```
SOLVER_API_URL=https://<host>/v1
SOLVER_API_KEY=<ключ>
SOLVER_MODEL=<модель>
```

Без настроек сайт работает только прогоном инструментов.

## Режимы запуска

- **Docker** → изолированная песочница (`site/sandbox/runner.py`, #142).
- **Без Docker** → локальный запуск без изоляции; страница предупреждает.
