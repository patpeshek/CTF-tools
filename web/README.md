# web

- `recon.py` — разведка страницы: заголовки/куки/JWT/комментарии/формы/ссылки/JS/robots, флаги.
- `jwt_tool.py` — decode/forge/verify без зависимостей. HS256/384/512 и `alg:none`.
- `jwt_brute.py` — подбор HMAC-секрета по словарю, опционально сразу новый токен.
- `ssti_probe.py` — поиск шаблонизатора по параметру (Jinja2/Twig/Freemarker/…).
- `param_probe.py` — прогон payload'ов по параметрам URL (SQLi/XSS/траверсал), сравнение с базой, поиск флагов в ответах.
- `dir_fuzz.py` — облегчённый перебор директорий/файлов.
- `gitdump.py` — открытый `.git`/`.svn` и типовые бекапы → восстановление
  исходников (loose-объекты и pack с дельтами, свой парсер, без запуска git).

Полный гид по веб-задачам — `../WEB.md` (recon, SQLi, XSS, SSRF, JWT, десериализация,
JS-консоль и готовые сниппеты).
- `web_checklist.md` — что проверять: IDOR, SQLi, LFI, JWT, SSTI, бизнес-логика,
  загрузка файлов, нестандартные методы.

Инструменты, которые держи под рукой: Burp Suite, gobuster/dirsearch/ffuf, sqlmap,
браузерные DevTools. Исходники, если дали, читать первыми.
